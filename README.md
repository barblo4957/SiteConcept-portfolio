# 🚀 SiteConcept v2 — AI-Driven Web Experience (2026)

**SiteConcept** to butikowa agencja budująca wysokowydajne platformy webowe zintegrowane z autonomicznymi systemami AI. To nie są zwykłe strony www — to cyfrowe ekosystemy, które zarabiają, gdy ich właściciele odpoczywają.

## 💎 Kluczowe Funkcje (The Edge)

* **Autonomous Sales Visualization** – Dynamiczna, animowana karta Bento wyświetlająca w czasie rzeczywistym symulację przychodów i operacji nocnych AI.
* **Dual-Engine i18n** – Pełna obsługa języka polskiego i angielskiego (PL/EN) bez przeładowywania URL.
* **Performance 99+** – Architektura oparta na Server Components (Next.js 16) dla błyskawicznego ładowania.
* **Legal-Ready** – System zgód Cookie i Polityka Prywatności zgodna z RODO.
* **Real World Case Study** – Implementacja dla marki **Integra Automatyka** (z systemem Cal.com).

## 🚀 Szybki Start

1. **Klonowanie repozytorium:**
   ```bash
   git clone [https://github.com/barblo4957/SiteConcept_NewChapter.git](https://github.com/barblo4957/SiteConcept_NewChapter.git)
   cd SiteConcept_NewChapter

2. Instalacja zależności:

RESEND_API_KEY=twoj_klucz_api
npm install

3. konfiguracja środowiska (.env.local):

RESEND_API_KEY=twoj_klucz_api
CONTACT_EMAIL=hello@siteconcept.pl   

4. Uruchomienie silnika:
npm run dev
